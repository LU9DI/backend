# Agent Marketplace

Marketplace para publicação, descoberta, instalação e cobrança de agentes.

## Fases
1. catálogo de agentes próprios
2. instalação/configuração por empresas
3. métricas e cobrança
4. publicação de terceiros
5. revenue share e governança

Catálogo, avaliações e publicação ficam isolados do runtime compartilhado.
