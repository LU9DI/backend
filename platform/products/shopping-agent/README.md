# Shopping Agent

Agente pessoal de compras.

## MVP
- intenção de compra em linguagem natural
- pesquisa e comparação de ofertas
- orçamento e preferências
- monitoramento de preço
- alertas
- histórico
- explicação da oferta

## Primeiro MVP não inclui
- execução automática de compras
- armazenamento desnecessário de dados de pagamento

Auth, billing, IA, notificações, jobs, segurança e observabilidade serão compartilhados.
