# Restore Server

Este documento é histórico. O runtime atual usa relatório profissional estruturado e não possui geração de arquivos de relatório.

Ao restaurar uma versão antiga, valide antes de promover: /api/live, /api/ready, /api/health, /api/planos e /api/empresa/:ref/relatorio.

Não reative componentes de geração de arquivo ou automação de navegador.
